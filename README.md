# SGCC - sistema de Gestion de Cursos de Conducción 

## Descripción 
 
El Sistema de Gestión de Cursos de Conducción (SGCC), es una plataforma digital diseñada para automatizar y optimizar los procesos académicos, administrativos y de control que se desarrollan en los Centros de Enseñanza Automovilística (CEA).
